# Changelog

All notable changes to this extension are documented here. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.19] - 2026-10-07

### Changed
- Storefront colours follow the store palette: muted text #525252 (was #737373), link hover and accent #115E59 and #0F766E, light backgrounds #FAFAFA (were #F1F5F9), section lines #E5E5E5 (were #CCFBF1) and the notice border #FEF3C7. Focus rings and shadows use the brand colour.
- Small corner radii use the shared small radius token.
